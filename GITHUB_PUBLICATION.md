# Publicação via GitHub

1. Crie um repositório privado chamado `via-commanddesk`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. No Vercel, abra `via-commanddesk-v4-1-pilot`.
4. Em Configurações → Git, conecte o repositório `via-commanddesk`.
5. Confirme a branch principal.
6. Faça um novo deploy.
7. Teste `/api/health`.

Não publique apenas `pilot.html`: o projeto depende das pastas `app/`, `lib/`, `public/` e das dependências do `package.json`.
